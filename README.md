# Айда кайрамар

Ретро-гонка для друзей: старт в Чебоксарах, Москве, Щёлкове или Подольске, финиш — на даче в Аксиньино.

Играть: https://logunovaleksey-prog.github.io/aida-kairamar/

Телефон держать горизонтально. Слева крестовина — руль, справа кнопки: B — газ, A — тормоз, Y — нитро, X — бибика.
На компьютере: стрелки, X — газ, Z — тормоз, C — нитро, H — бибика, Esc — пауза.
